  <action>
    Diseña e implementa un banner deslizante continuo (marquee) e interactivo posicionado inmediatamente debajo de la barra de navegación principal (Navbar).
  </action>

  <subject_and_context>
    La cinta debe servir como una vitrina de acceso rápido para los servicios recientemente optimizados del sitio. Cada texto del servicio debe actuar como un enlace hipertexto que dirija a su respectiva página de servicio (donde se encuentran integrados los nuevos formularios de captura).
    
    Enlaces de destino específicos:
    - **Regularización de Viviendas / Inmuebles**: `/regularizacion.html`

    - **Contacto General y Calificación**: `/contacto.html`
  </subject_and_context>

  <constraints>
    1. **Dirección de Movimiento**: Desplazamiento horizontal continuo de derecha a izquierda.
    2. **Control de Interacción (Hover Pause)**: Cuando el usuario acerque el cursor al texto de la cinta, la animación debe detenerse (`animation-play-state: paused`) de forma inmediata. Al retirar el cursor, debe reanudar su marcha de manera fluida.
    3. **Efecto de Bucle Infinito Simétrico (Seamless Loop)**: Duplica la lista de elementos en el DOM (Grupo 1 y Grupo 2) para lograr un scroll sin cortes visibles ni saltos bruscos cuando la animación se reinicie.
    4. **Estilo Visual Limpio**:
       - Fondo de alto contraste alineado con el diseño del sitio (ej. Gris muy oscuro o negro: `bg-slate-900` / `bg-gray-950`).
       - Texto claro y legible con tipografía profesional (ej. `text-sm font-semibold tracking-wide text-slate-200`).
       - Separadores elegantes entre cada enlace de servicio (como un rombo pequeño o punto medio destacado `◆` en color contrastante).
    5. **Código Limpio y Rendimiento**: Prioriza una animación gestionada 100% por CSS (`keyframes` y `transform: translateX`) para asegurar que la CPU rinda de forma óptima en dispositivos móviles sin usar JavaScript innecesario.
  </constraints>
